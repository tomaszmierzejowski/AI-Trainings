About confidence scores

Confidence uses the Evidence Coverage Index (ECI): 50% evidence breadth + 35% verification of critical findings + 15% analysis coverage. Tiers: Very High 90-100 · High 70-89 · Medium 50-69 · Low 30-49 · Very Low 0-29, rounded to the nearest 10. A score answers "where should further discovery focus?" — the per-finding evidence badge answers "can this finding be believed?"

Modernization Roadmap

Phase 0 — Foundations

API gateway, service registry, shared authentication. Exit gate: first domain service routable through the gateway.

Phase 1 — Pilot domain

Extract the Sales domain (highest duplicate density, TDP-DUP-01/02). Exit gate: quoteweb reads customers via API, not schema.

Phase 2 — Progressive extraction

Remaining domains by fan-in order; retire cross-schema references as each domain lands.

Decision gate

Re-score the portfolio; confirm or adjust the remaining sequence with the client team.

Reduced operational risk

Eliminates the shared-schema single point of failure.

Faster time to market

Domain services deploy independently.

Enhanced security

Unified authentication at the gateway.
