## Anonymization Policy

This folder contains **zero customer-identifying information**. All case studies use codenames:

| Codename | What can be said publicly |
|----------|--------------------------|
| **Project Proof of Scale** | Enterprise automotive dealer platform discovery |
| **Project Invisible Risk** | Nordic tolling/billing platform discovery |
| **Project Proof of Speed** | Pediatric mobile health app emergency migration |
| **Project The Rescue** | Ocean research data collection system rescue |

**Never include in this folder or any derivative content:**
- Customer organization names
- Currency amounts or customer-specific pricing
- Sopra Steria internal cost estimates
- Customer-specific compliance scores
- Customer employee names

**Can include (anonymized):**
- Technical facts (stacks, repo counts, page counts, timelines)
- Methodology facts (team sizes as "1.5 consultants", discovery duration)
- Verified metrics (92% code preservation, 200+ CVEs, etc.)
- The stories behind the discoveries (currency mismatch detective work, Christmas Eve rescue)
- Codenames only
